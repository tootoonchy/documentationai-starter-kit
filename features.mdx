## Ask Humanic

You use Ask Humanic to search a directory of authentic conversations. The tool returns answers from founders, investors, and operators instead of generic AI output.

<Tabs>
  <Tab title="Web Interface" icon="globe">
    Enter your question directly in the search bar. Results include source timestamps and speaker context.
  </Tab>
  <Tab title="API Access" icon="code">
    Integrate queries programmatically for custom applications.
  </Tab>
</Tabs>

````javascript
const response = await fetch('https://api.humanic.fm/ask', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    query: "How did you validate your first startup idea?",
    limit: 5
  })
});
const data = await response.json();
console.log(data.results);
````

## Humanic Studio

You leverage Humanic Studio for end-to-end episode production. The studio combines voice synthesis, segment editing, and export tools.

```bash
# Example CLI command to render an episode
humanic studio render --episode-id ep_12345 --format mp3
```
